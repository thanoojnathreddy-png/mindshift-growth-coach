# MindShift Growth

Build MindShift – MVP

Build a modern, beautiful, responsive web application called MindShift.

Vision

MindShift is not a habit tracker or a reminder app.

It is an AI-powered personal growth platform that helps people stop repeating the same mistakes or unhealthy habits by combining self-reflection, accountability, and personalized coaching.

The goal is to make users feel understood and motivated—not judged.

The design should feel premium, calming, minimal, and trustworthy.

Design Style

Create a clean modern SaaS interface.

Use:

Soft gradients

Rounded cards

Smooth animations

Glassmorphism where appropriate

Excellent spacing

Modern typography

Beautiful icons

Responsive design

Dark mode and Light mode

Professional startup-quality UI

The application should feel like a product from Apple, Notion, or Linear.

Build Only the MVP

Do NOT build premium features yet.

Create these pages only.

1. Landing Page

Include:

Hero section

Strong headline:
"Stop Repeating The Same Mistake."

Subtitle:

"MindShift helps you break recurring habits through AI-powered coaching, daily accountability, and emotional support."

Buttons:

Get Started

Learn More

Also include:

Features

How it Works

Testimonials (dummy data)

FAQ

Footer

2. Authentication

Create:

Sign Up

Login

Forgot Password

Keep the UI modern and elegant.

3. Onboarding

After signing up, ask the user:

What mistake or habit do you want to change?

Why do you want to change?

What usually triggers it?

What kind of person do you want to become?

Store these answers.

4. Dashboard

Display:

Welcome message

Current commitment

Today's motivation card (placeholder for now)

Current streak

Success rate

Today's check-in button

Progress summary

Clean navigation sidebar

5. Daily Check-in

Ask:

Did you repeat your mistake today?

Options:

Yes

No

If Yes:

Ask:

What happened?

What triggered it?

How did you feel?

Store these responses.

6. Progress Page

Show:

Current streak

Longest streak

Success percentage

Calendar view

Weekly progress chart

Monthly progress chart

Use placeholder data if needed.

Technical Requirements

Frontend:

React

TypeScript

Tailwind CSS

Use reusable components and clean project structure.

Do not integrate AI or notifications yet. Leave clear placeholders where those features will be added later.

Generate production-quality code with maintainable components and a polished user experience.
